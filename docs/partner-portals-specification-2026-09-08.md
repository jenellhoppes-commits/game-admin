# 代理後台／商戶後台詳細規格與 UI 排列

版本：2026-09-08，依本次使用者確認整合。本文為需求基準；「本輪變更」與「沿用規格」不代表所有功能均於本輪重新驗收。既有文件衝突時，以本文及使用者後續確認為準。

## 1. 架構與角色

- 沿用現有遊戲商總後台，同一網站、同一登入頁選擇管理者／代理／商戶，登入後進入對應路由。
- 管理者保留原路由；代理 `/agent/*`；商戶 `/merchant/*`。旧原型端口不是獨立正式產品。
- 共用頁首、側欄、搜尋、表格、日期元件、抽屜、對話框與明暗主題。不得以重複手刻表單形成不同操作規則。
- 切換登入身分需清除上一身分的頁籤與授權資料視圖；直接輸入網址也必須檢查角色及資料範圍。
- 代理只看授權代理樹及商戶彙總；商戶只看本商戶和授權線路。正式環境須由服務端驗權，不能只靠前端選單。

## 2. 共通 UI 排列

| 區域     | 排列建議與規格                                                                 |
| -------- | ------------------------------------------------------------------------------ |
| 側欄     | 代理／商戶各自一層功能選單，避免唯一父層再包同一組功能                         |
| 頁首     | 麵包屑、頁名、簡短用途；右側僅放本頁主要操作                                   |
| 查詢區   | 位於列表上方，標籤置頂；桌機依容器寬度排 2–4 欄，手機單欄                      |
| 查詢按鈕 | 查詢為主按鈕、重置為次按鈕；窄螢幕換行，不擠壓欄位標籤                         |
| 列表     | 共用表格、分頁、空狀態；金額靠右、代碼與日期不任意拆行                         |
| 詳細內容 | 基本資料 → 商務條件 → 條件歷史 → 操作紀錄；其他業務資料放相應頁籤              |
| 表單     | 基本資料在前，條件在後；桌機兩欄、手機單欄；必填有標示並在保存時驗證           |
| 抽屜     | 標題與關閉置頂，內容區捲動；操作區與內容分離，底部安全間距不可被手機工具列遮住 |
| 長表格   | 只允許表格容器橫向捲動；整頁、表單及底部按鈕不可被帶出螢幕                     |
| 分頁     | 桌機顯示總筆數／頁碼／每頁筆數；窄螢幕優先保留總筆數及上一頁／下一頁           |
| 提示     | 移除失效的申請說明、缺少來源等開發註解；保留真實錯誤、唯讀與必要業務提示       |
| 手機     | 控制項文字建議至少 16px，避免輸入自動放大；不以禁用使用者縮放取代響應式排版    |

UI 建議中尚未實作的全站視覺調整應獨立記錄，不混入本次條件流程變更。

## 3. 代理後台選單

1. 儀錶板
2. 代理關係
3. 商戶管理
4. 代理報表
5. 匯率報表
6. 對帳／結算
7. 公告通知
8. 帳號與權限

移除獨立「商務條件」選單，舊網址導向代理關係。自己的條件在代理關係自己的節點中唯讀查看；下級及商戶條件在各自詳細內容管理。

### 3.1 儀錶板

- 上方期間／原幣查詢，下方代理與商戶數量摘要，再放待辦與分幣營運摘要。
- 代理數量區分直屬及全部後代；商戶區分直屬及覆蓋商戶，資料去重。
- 營運摘要包含投注、派彩、遊戲輸贏、局數，原幣分列，不直接跨幣加總。
- 參考換算須標示「該金額只可參考」，不能代替結算金額。
- 移除新增商戶的待審申請待辦。關係待審只計入尚需審核的停用／移轉事項；保留待確認對帳與未讀公告。
- UI：摘要卡保持同高，幣別摘要用緊湊列表，避免每個幣別一張超高卡片。

### 3.2 代理關係與新增代理

- 桌機左側代理樹，右側選中代理的詳細資料；下方可查詢後代列表。手機上下排列。
- 點選樹節點或列表名稱，顯示同一對象，不另開重複資料來源。
- 新增代理直接建立，不送審。本代理只能建立自己的直屬下級；L3 不可新增下一級。
- 名稱必填 1–80 字；同一上級不可有重複名稱。代碼由系統產生且不可重複；層級依上級判斷。
- 基本資料：上級（目前代理）、名稱、代碼（建立後顯示）、層級、備註。
- 商務條件：計算基礎、比例、結算幣別、對帳週期、生效日均必填。
- 計算基礎固定 GGR（遊戲輸贏），三個後台均移除有效投注／總投注的商務條件選項。比例 0–100%，沿用兩位小數。
- 週期選項：日結／週結／半月結／月結。週期只是頻率，不自行補定未核准的收益公式或出帳截止細則。
- 一次建立代理與 V1 條件。任一驗證失敗都不得留下代理或條件的半套資料。
- 停用及移轉仍沿用既有申請流程，本輪不改成直接執行。

### 3.3 商戶管理與新增商戶

- 查詢：直屬／間接、代碼或名稱、直接代理、狀態、投注幣別。
- 列表：代碼、名稱、關係、所屬代理、狀態、幣別及既有營運摘要；詳細按鈕進入商戶資料。
- 新增限目前代理的直屬商戶，直接建立，不送審。
- 必填基本資料：商戶代碼、商戶名稱、投注幣別；備註選填。
- 商戶代碼為 2–24 字英數及 `-`、`_`，正規化大寫並檢查重複。
- 商務條件改為直接填寫：GGR（固定）、比例、結算幣別、對帳週期、生效日；另選擇錢包類型。
- 錢包：單一錢包 Seamless／轉帳錢包 Transfer。
- 不使用既有商務條件下拉選單；代理及商戶新增共用相同的條件欄位組件。
- 填寫內容保存為該商戶獨立 V1，不能引用其他商戶條件代替填寫。
- 建立商戶不等於已配置遊戲、線路、憑證或登入帳號，這些沿用其既有管理流程。
- 代理端商戶詳細只提供授權商務摘要，不揭露逐筆注單、會員個資及串接秘密。

### 3.4 整合的商務條件

| 頁籤     | 顯示與操作                                           |
| -------- | ---------------------------------------------------- |
| 基本資料 | 對象名稱、代碼、關係及既有摘要                       |
| 商務條件 | 生效中條件、待生效版本；直屬對象顯示「修改條件」     |
| 條件歷史 | 版本、基礎、比例、結算幣、週期、生效期間、狀態、原因 |
| 操作紀錄 | 時間、操作人、動作、結果，展開查看修改前後內容及原因 |

- 自己的條件唯讀；直屬下級代理與直屬商戶可修改；間接對象依授權唯讀；其他代理樹不可存取。
- 修改欄位：計算基礎、比例、結算幣別、對帳週期、生效日、變更原因。
- 保存建立新版，不覆寫舊版；不建立條件申請或待審核提醒。
- 每次新增條件及修改都必須有有效日期，拒絕空值、無效日期及過去日期。
- 本原型業務日期使用 Asia/Taipei，表單明示。同日保存即啟用；未來日期標示待生效。
- 到日切換後，上一版本標示已到期；結束日期採不包含當日，新版本從當日開始。
- 同一對象同日不得有重複的生效中／待生效版本。
- 新日期不修改已鎖定帳單或歷史條件快照。未結算資料跨版本分段計算仍須依確認的結算算法實作，不能以換算預覽代替。
- 本地原型於開啟、回到視窗及每 30 秒檢查到期版本；關閉瀏覽器時不執行背景排程，再次開啟會補套用。正式環境需服務端排程與持久稽核。
- 過去無日期草稿不補造日期，保留歷史；舊申請不改寫成成功操作。

### 3.5 代理報表

- 以授權代理／商戶集合分析，直屬與間接不重複計入。
- 日期範圍與快捷：本日、昨日、本週、上週、本月、上月。週起日與業務時區須與既有報表一致。
- 必含明細列表及分幣總計，顯示查詢期間、代理範圍及原幣。
- 提供指定幣別的參考換算；醒目標示「該金額只可參考」，並顯示採用匯率日期／版本。
- 缺少匯率不填 0 或自行估價；標示無法換算，保留原幣結果。
- 不展示會員個資、逐筆下注、資金交易及重播；未定收益算法不產生正式收益金額。
- UI：篩選 → 參考換算（可選）→ 列表 → 分幣總計。數字靠右，幣別獨立欄位。

### 3.6 匯率報表

- 正式適用匯率／歷史快照兩個頁籤；可依日期及目標幣查詢、查看詳細。
- 顯示基準幣、目標幣、匯率、生效期間、版本。長匯率用足夠欄寬，避免幣碼換行擠壓。
- 唯讀，不能新增、修改、停用、刪除、鎖定或建立快照；不展示內部來源成本或加減點。

### 3.7 對帳／結算

- 本代理單據列表 → 詳細 → 差異回報或確認本版本。
- 顯示期間、幣別、條件版本、匯率快照、金額及狀態。
- 有未解決差異或缺少必要快照時依既有規則阻擋確認；只能確認本身單據。
- 差異回報記錄關聯參照、金額、原因；不修改原始交易。
- UI：單據摘要在前、明細居中、差異及確認分區；禁止因表格固定高度產生大段空白。

### 3.8 公告與帳號

- 公告列表／詳細、已讀狀態；只顯示授權公告。
- 本代理員工帳號及角色依既有權限管理，停用後不可繼續執行操作。
- 權限不能超過目前代理授權，也不能透過員工設定取得其他代理樹資料。

## 4. 商戶後台詳細規格

商戶是使用遊戲的角色；商戶自己的商務條件由所屬代理或總後台設定，商戶不能修改費率或對帳週期。

| 選單 | 核心內容與操作 | UI 排列 |
| --- | --- | --- |
| 儀錶板 | 本商戶營運摘要、授權線路、待確認對帳及公告 | 期間 → 指標 → 分幣摘要／待辦 |
| 遊戲中心 | 查看已授權遊戲、狀態、RTP 與線路配置；可關閉在自己平台顯示 | 查詢 → 遊戲列表 → 詳細；關閉操作放獨立底部區 |
| 線路管理 | 查看本商戶已授權線路、環境、幣別、遊戲配置 | 列表 → 基本資料 → 遊戲配置 |
| 串接中心 | 查看既有串接狀態及已提供的文件／資訊 | 狀態摘要 → 串接資料；不放申請紀錄 |
| 會員中心 | 本商戶授權會員查詢與既有詳細內容 | 篩選 → 列表 → 詳細；權限範圍外資料不載入 |
| 交易中心 | 下注紀錄、資金交易與關聯詳細 | 頁籤 → 查詢 → 列表 → 詳細 |
| 獎池 | 查看本商戶可見的獎池資料與紀錄 | 獎池列表 → 詳細／紀錄 |
| 營運報表 | 本商戶／線路範圍分析、列表與分幣總計 | 日期快捷 → 查詢 → 參考換算 → 列表／總計 |
| 匯率報表 | 正式匯率、歷史快照與詳細，完全唯讀 | 正式適用／歷史快照 → 查詢 → 表格 |
| 對帳／結算 | 查看及確認本商戶對帳、回報差異 | 摘要 → 明細 → 差異／確認 |
| 公告通知 | 閱讀本商戶公告與通知 | 列表 → 詳細 |
| 帳號與權限 | 本商戶員工及既有授權管理 | 查詢 → 帳號／角色 → 編輯表單 |

### 4.1 遊戲、線路與串接限制

- 遊戲中心移除全部遊戲申請內容；不能修改遊戲主資料、RTP 或他商戶配置。
- 「關閉本平台遊戲」只影響本商戶展示；不能停用總後台主遊戲。是否允許重新開啟沿用既有核准範圍，不增加新權限。
- 串接中心不顯示申請紀錄；資料不存在時顯示正常空狀態，不留下開發說明段落。
- 錢包類型在建立商戶時指定。商戶後台不提供任意切換錢包的操作。

### 4.2 下注詳細與重播

- 基本資料、遊戲結果、關聯交易、異常紀錄及既有原始結果權限保持一致。
- 「重播與盤面」為下注詳細內的單一頁籤，還原保存的歷史結果，不重新產生遊戲結果。
- 缺少重播資料顯示無資料，不以亂數補結果。
- 返回列表保留原查詢、頁碼及每頁筆數。

### 4.3 商戶報表與結算

- 日期快捷同代理：本日／昨日／本週／上週／本月／上月。
- 列表、總計與詳細的原幣數字一致。不同幣別不得直接相加。
- 參考換算顯示「該金額只可參考」，不作對帳確認依據。
- 商戶只確認自己的單據，不能確認代理單據；差異流程不改原始注單。
- 條件版本及匯率快照沿用該單據當時採用內容，不被新設定覆蓋。

## 5. 本輪修改與驗收範圍

歷史非 GGR 條件及已結算快照不改寫成 GGR；新增或修改時僅接受 GGR。報表的投注指標不屬於本次移除範圍。

本輪修改：代理新增附帶條件、商戶新增必填日期、直屬對象直接修改條件、共用條件面板、版本生效檢查、操作紀錄、移除獨立條件選單及商戶待審新增待辦。

驗收需涵蓋：

1. 缺條件／缺日期時拒絕建立且無半套資料。
2. 同日立即生效、未來保留舊版、到日切換與多日離線補套用。
3. 重複日期及越權修改拒絕；生效切換多次執行不重複記錄。
4. 原帳單、原始交易及歷史快照不變。
5. 刷新後代理、商戶及新條件版本保留。
6. 代理自己的條件唯讀；直屬可改、間接不可改。
7. 桌機及手機的新增表單、詳細頁籤和保存按鈕可見可用。
8. 舊條件網址可導向新位置；總後台共用資料與主要條件讀取不被破壞。

## 6. 仍需另行確認／正式化

- 收益算法、跨條件生效日的未結算分段算法及週期截止細則。
- 生效日是否未來需要可配置時區；本原型明示 Asia/Taipei。
- 正式 API 的原子交易、後端授權、排程、併發版本控制與持久稽核。
- 頁面原型測試通過不等於上述後端功能已完成。

商戶其餘頁面沿用既有規格，本次整理不代表重新開發所有商戶功能，也不恢復已暫停的「安排選手」追蹤流程。
