# 成本比例與結算方式補充規格（2026-09-09）

本次確認優先於舊版規格。

- 條件依遊戲類型設定，計算基準只有 GGR。
- 上級提供的比例為成本。同類型下開比例必須大於或等於成本；相等時差額為零。缺少類型成本時不能自行假定為零或套用歷史全域比例。
- 例如正 GGR 1,000,000，上級成本 5% 為 50,000，下開 6% 為 60,000，差額 10,000。
- 總後台及代理新增、修改條件均記錄生效日及版本；商戶觀看自己的條件。
- 結算方式只有「清零／累積」，不使用「累計」。新類型條件必填；歷史未設定值保留為未設定。
- 對帳及結算單增加「上期累積金額」。尚未提供的歷史金額顯示待定，不當作零。
- 本次原型保存並顯示結算方式，不自動更動既有應付金額或歷史結算。
- 清零時點、正負金額結轉、首期金額、模式切換及上級成本調高後的既有下級條件，留待營運規則確認。

驗證：類型成本相等、高於、低於、缺少成本，以及錯誤結算方式；直接新增、版本排程與歷史不變回歸測試。
