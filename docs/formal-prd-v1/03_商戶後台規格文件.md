## 1. 這頁是什麼

| 功能 ID | 使用者要做的事 | 核心規則 |
| --- | --- | --- |
| MER-01 | 商戶儀錶板 | 只統計本商戶授權線路；原幣分列；待辦指向自己的帳單及公告。 |
| MER-02 | 遊戲中心 | 總後台未授權的遊戲不可見；已授權遊戲的主資料及 RTP 唯讀。沒有任何遊戲申請功能。 |
| MER-03 | 本平台遊戲開關 | 只控制自己平台展示；不修改總後台主檔及授權。自行關閉後本後台仍看得到，依授權可重新開啟。 |
| MER-04 | 幣別與限紅 | 只選總後台相符啟用方案；不可自填最低／最高金額；保存重新驗權與方案狀態；總後台可看到同筆更新。 |
| MER-05 | 線路管理 | 可申請首條幣別線路；只選總後台啟用交易幣；同幣未關閉線路或待審申請存在時拒絕重複。核准前不生效。 |
| MER-06 | 串接中心 | 只查看本商戶串接與可提供的文件；沒有申請紀錄。不能切換錢包、核准正式環境或暴露機密憑證。 |
| MER-07 | 會員中心 | 只存取本商戶及授權線路的會員紀錄。不可透過修改識別查看其他商戶。 |
| MER-08 | 交易中心 | 注單與資金交易保持關聯；重播是同一頁籤的歷史結果還原。無保存結果顯示缺少資料，不生成假結果。 |
| MER-09 | 獎池 | 僅本商戶授權獎池及自身紀錄；不能改全域池或其他商戶綁定及派發。 |
| MER-10 | 營運報表 | 查詢與摘要同一商戶線路集合；原幣及參考金額分開；參考不可作確認帳單的金額。 |
| MER-11 | 匯率報表 | 只觀看正式適用資料及歷史，不可維護、產生快照或讀內部加點成本。 |
| MER-12 | 對帳／結算 | 自身條件只讀，包含逐類型 GGR 比例及清零／累積；只確認本商戶單據。保留至下期與負 GGR 扣抵遵循共通規則。 |
| MER-13 | 公告通知 | 只看本商戶授權公告；讀取不修改其他使用者閱讀狀態。 |
| MER-14 | 帳號與權限 | 不可超出本商戶已授權線路；停用或撤權後停止存取；正式帳號邀請服務另需串接。 |

### 共通業務規則

| 規則 | 主題 | 內容 |
| --- | --- | --- |
| C01 | 身分與資料範圍 | 同一登入入口依帳號身分進入總後台、代理或商戶後台。服務端依已驗證身分判斷資料與操作範圍；客戶端傳入其他對象識別不會擴張授權。列表、摘要、詳細、下載及修改適用相同範圍。 |
| C02 | 唯一設定來源 | 遊戲類型、幣別、RTP 方案及限紅方案由總後台維護。代理、商戶只使用授權且有效的同一來源。新設定不覆蓋歷史注單、條件版本及結算快照。 |
| C03 | 商務計算基準 | 新增及修改條件只接受 GGR。有效投注與總投注不可作新商務條件基準；投注等營運統計指標仍保留。舊非 GGR 與歷史全域條件保留歷史，不自動轉換。 |
| C04 | 各遊戲類型獨立條件 | 每個版本至少一個類型；同類型不可重複。SLOT 5%、LIVE 8% 為確認範例，不是全部對象預設費率。比例範圍 0–100%，最多兩位小數。留空為未設定，不能當 0%。版本共用結算幣別、週期、生效日、結算方式與原因。 |
| C05 | 下開成本下限 | 上級給本代理的同類型比例是成本。下開直屬代理或商戶的比例必須大於或等於適用上級成本。5% 成本允許 5% 或 6%，拒絕 4.99%。缺少該類型成本時拒絕，不套用其他類型或舊全域比例。 |
| C06 | 日期與版本 | 每次建立、修改條件必填生效日；沿用 Asia/Taipei 業務日期。過去或無效日期拒絕；同一對象同日不可有重複有效／待生效版本。新版本從生效日開始，前版本截止日不含新版本生效當日。總後台草稿經確認後排程；代理直接保存版本。同日生效，未來待生效；服務端負責到期切換及持久紀錄。 |
| C07 | 歷史與稽核 | 任何版本切換不可回寫已鎖定對帳、已保存交易及歷史結果。修改留存對象、操作人、時間、動作、原因、前後值、結果及關聯版本；失敗不留下半套業務資料。重送不得重複建立或結轉。 |
| C08 | 原幣與參考換算 | 列表、明細、總計使用同一查詢範圍，按原幣分組。使用者可選一個幣別預覽，必須標示「該金額只可參考」並提供匯率日期／版本。缺匯率不填 0，不把部分換算當全部總額。預覽不改應付金額。 |
| C09 | 清零與累積 | 新條件必填清零或累積，不能使用「累計」。累積承接負 GGR 下期扣抵；清零下期不承接負 GGR。兩種模式均保留「保留至下期交收」，均承接尚未交收金額。既有待交收款不可因清零被刪除。 |
| C10 | 確認與交收分離 | 對帳確認只確認單據版本，不代表付款。未解決差異、缺必要計算或匯率快照時不可確認。每期確認後可保留或交收；已交收部分不再結轉。正式交收憑證與入帳整合另待外部輸入。 |

### 結轉計算與可重現例子

本節定義已確認的單一幣別、同類型、同費率跨期規則。跨費率及跨模式切換列於待確認，不自行推算。

| 項目 | 規則 |
| --- | --- |
| 扣抵後 GGR | 上期累積 GGR ＋ 本期 GGR；本期 GGR 本身不包含以前期別。 |
| 本期新增交收金額 | 扣抵後 GGR 大於 0 時乘適用類型比例；否則為 0。 |
| 合計待交收金額 | 上期待交收金額 ＋ 本期新增交收金額。上期待交收款已經計價，不再乘比例。 |
| 結轉下期待交收金額 | 合計待交收金額 − 本期實際交收金額。保留時實際交收為 0。 |
| 下期累積 GGR | 累積模式承接 min(扣抵後 GGR, 0)；清零模式為 0。正 GGR 計價後不再承接成 GGR。 |
| 隔離 | 按交易對象、幣別、遊戲類型及適用條件版本追溯。不同幣別不可直接相加；不得把其他對象餘額帶入。 |
| 演示界線 | 現有「交收結轉演示」固定 SLOT／USD／5%，提供全額交收及保留。不是正式帳單入帳證明；部分交收及正式精度待決策。 |


| 模式／期別 | 上期 GGR | 本期 GGR | 扣抵後 | 上期待交收 | 新增 5% | 動作／下期待交收 |
| --- | --- | --- | --- | --- | --- | --- |
| 累積 P1 | 0 | -100,000 | -100,000 | 0 | 0 | 保留／0，負 GGR -100,000 承接 |
| 累積 P2 | -100,000 | 60,000 | -40,000 | 0 | 0 | 保留／0，負 GGR -40,000 承接 |
| 累積 P3 | -40,000 | 100,000 | 60,000 | 0 | 3,000 | 保留／3,000，GGR 不再承接 |
| 累積 P4 | 0 | 20,000 | 20,000 | 3,000 | 1,000 | 保留／4,000 |
| 累積 P5 | 0 | 0 | 0 | 4,000 | 0 | 全額交收 4,000／0 |
| 清零 P1 | 0 | 100,000 | 100,000 | 0 | 5,000 | 保留／5,000 |
| 清零 P2 | 0 | -40,000 | -40,000 | 5,000 | 0 | 保留／5,000；下期 GGR 0 |


金額範例以 USD 整數呈現。若 GGR 1,000,000，上游成本 5% 為 50,000，下開 6% 為 60,000，該同基礎例子的差額為 10,000。此例不代表已決定跨類型負數互抵或所有代理樹分潤分配。

## 2. 這頁不做什麼

| 不做的事 | 由誰負責 |
| --- | --- |
| 以演示保存結果宣稱正式付款 | 正式財務入帳／交收服務及其負責團隊 |
| 以參考換算改正式對帳金額 | 正式結算計算與版本快照 |
| 把其他商戶或其他代理樹資料當自己的 | 服務端授權與對象範圍驗證 |
| 自行補定待決的跨期、跨類型策略 | 需求方與 PM 決議並更新 Q 編號 |
| 修改自身費率、RTP、主遊戲、錢包類型 | 上級代理或總後台 |
| 遊戲申請、串接申請紀錄 | 不提供；只有幣別線路仍有申請流程 |

## 3. 名詞說明

| 名詞 | 說明 |
| --- | --- |
| GGR／商務比例 | GGR 為計價基礎；比例是付給上級的成本百分比，與 RTP 不同。 |
| RTP | 遊戲核定返還方案；例 96.2% 不是商務費率 5%。 |
| 線路／限紅 | 線路固定一交易幣；限紅設定以商戶×線路×遊戲選方案。 |
| 商戶授權／本平台關閉 | 總後台取消授權使商戶遊戲中心看不到；商戶自行關閉仍保留後台可見性。 |
| 上期累積 GGR／上期待交收 | 前者未計價負 GGR，後者已計價未交收款；例如 -40,000 與 3,000 不能直接視為同一種餘額。 |
| 確認／鎖定／交收 | 確認是帳務版本核對；鎖定限制改寫；交收才減少待交收金額。 |
| 版本／快照 | 條件版本與實際交易、結算使用快照分離；新版本不回寫歷史。 |
| 直屬／間接 | 直接父子或直接代理商戶關係為直屬；後代中的其他對象為間接，不重複計算。 |

## 5. 欄位說明

| 欄位 | 內容與驗證 | 無資料時顯示 |
| --- | --- | --- |
| 對象識別／名稱 | 代理、商戶、會員或遊戲的唯一身分；名稱不是授權依據 | 未提供；必要識別缺失禁止提交 |
| 遊戲類型 | 總後台類型代碼及名稱，例如 SLOT／電子遊戲 | 未設定，不借用其他類型 |
| GGR 比例 | 依類型百分比；新建 0–100%，兩位小數；下開須符合成本 | 未設定，非 0% |
| 條件版本／生效期間 | 版本、起日、截止日；截止不包含新版本起日 | 歷史缺日期顯示未提供；不可補造 |
| 結算幣別／週期 | 有效結算幣；日結、週結、半月結、月結 | 未設定，建立時拒絕 |
| 結算方式 | 清零／累積；新條件必填 | 未設定，不自選模式 |
| 錢包類型 | Seamless 單一錢包／Transfer 轉帳錢包；商戶層級 | 未設定，不代表任一模式 |
| 線路／交易幣別 | 一線路一交易幣別；商戶身分和線路歸屬必須一致 | 尚無線路；可申請第一條 |
| RTP 方案 | 商戶 × 遊戲核定方案、值與版本；非商務 GGR 費率 | 未配置，不填 0% |
| 限紅方案 | 商戶 × 線路 × 遊戲所選方案；最低／最高投注及幣別 | 未配置；無相符啟用方案不可保存 |
| 本期 GGR | 本期來源統計，未加入歷史 GGR 或歷史款項 | 未提供，非 0 |
| 上期累積 GGR | 尚未扣抵完的負 GGR；與已計價款分離 | 首期須有明確零餘額依據；缺來源顯示待確認 |
| 扣抵後 GGR | 上期累積 GGR 加本期 GGR | 缺任一必要輸入則無法計算 |
| 上期待交收金額 | 以前各期已計價尚未交收款的承接餘額 | 未提供，不以 0 代替 |
| 本期新增交收金額 | 本期扣抵後正 GGR 依條件計價結果 | 必要費率或快照缺少時無法計算 |
| 合計待交收金額 | 上期待交收加本期新增；不重複計價 | 無法計算，不能確認正式交收 |
| 本期實際交收金額 | 本期完成交收的金額；保留為 0 | 尚未交收／未提供，區分真實零值 |
| 結轉下期待交收金額 | 合計減本期實際交收；後期以上期欄位承接 | 未完成計算 |
| 匯率／快照 | 基準幣、目標幣、適用率、生效期間、版本 | 未提供；不產生假換算 |
| 差異 | 關聯參照、金額、原幣、原因、處理狀態及版本 | 無差異／未提供，依查詢成功與否區分 |
| 稽核 | 操作人、時間、動作、原因、前後值、結果 | 未提供；不以目前帳號補歷史操作人 |
| 線路申請原因 | 提交申請的必要說明 | 未填拒絕提交 |
| 歷史重播 | 保存盤面、事件及結果版本；不是目前設定 | 缺少資料／部分可用／不支援 |
| 串接文件 | 只使用已核准提供的真實入口 | 未提供，不建立虛構連結 |

數值 0 只用於來源已確認為零；未提供、無權限與計算失敗不得轉為零。ID 用於關聯與稽核，不以名稱做資料關聯。

各欄位是否提供以第 1 章角色權限為準；共通名詞不額外授予操作。代理端不提供 RTP／限紅配置欄位或會員明細。商戶端商務條件、RTP 及匯率均唯讀。
