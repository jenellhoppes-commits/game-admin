# 代理與商戶後台結算設定補齊（2026-09-09）

## 代理後台
- 新增直屬代理、商戶時，填寫各遊戲類型 GGR 條件及清零／累積方式。
- 修改條件帶入原結算方式；生效日及原因仍須重新填寫，保存為新版本。
- 自身條件唯讀；直屬範圍依既有權限修改，不擴大至非直屬資料。
- 待生效及歷史版本獨立列出結算方式，方便比較。
- 對帳列表及明細維持顯示上期累積金額。

## 商戶後台
- 商務條件及結算方式維持唯讀，由授權上級設定。
- 對帳及結算列表、明細顯示結算方式與上期累積金額。
- 累積金額依結算幣顯示小數位及幣別，零顯示為零；缺少資料顯示待定。
- 歷史單據採用自身保存資料，不用最新商務條件覆蓋。

## UI 排列
- 條件設定：GGR 類型比例 → 結算方式與幣別 → 對帳週期與生效日。
- 商戶對帳：期間／線路 → 原幣及結算幣 → 結算方式及上期累積金額 → 本期數據與狀態。
- 沿用共用表格、抽屜及表單元件；長表格保留橫向捲動。

清零時點及結轉算法尚待確認。本次只補齊原型顯示及資料傳遞，不重新計算既有單據。
