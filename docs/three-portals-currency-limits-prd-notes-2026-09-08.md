# 三後台：幣別線路、RTP 與限紅規格紀錄

## 本次確認

使用者以演示正確為優先；不要求全面對齊模擬資料。本文保留正式 PRD 所需規則，前端演示與正式後端能力分開記錄。

## 權限與設定來源

| 項目 | 總後台 | 代理後台 | 商戶後台 |
| --- | --- | --- | --- |
| 可用幣別 | 管理啟用狀態、交易／結算用途 | 使用總後台選項 | 從開放交易幣別申請線路 |
| 商務條件 | 管理 | 直屬對象可依授權填寫 GGR 條件 | 自身條件唯讀 |
| RTP | 設定商戶 × 遊戲核定方案 | 不增加操作權限 | 唯讀 |
| 限紅方案 | 建立及維護遊戲 × 幣別的方案 | 不增加操作權限 | 選擇適用的啟用方案，不可自填金額 |
| 遊戲展示 | 管理主檔與商戶授權 | 不增加操作權限 | 保留關閉本平台遊戲 |

線路代表交易幣別；同商戶同遊戲的 RTP 不因線路幣別而另設。限紅粒度為商戶 × 線路 × 遊戲，必須符合線路幣別。

## 幣別線路申請

商戶線路管理 → 申請幣別線路 → 選擇幣別、填寫原因 → 總後台審核中心 → 核准／駁回 → 商戶申請紀錄與線路列表。

- 商戶由登入身分決定，不提供跨商戶選擇。
- 幣別須為總後台啟用且允許交易的幣別。
- 無線路的新商戶也可申請第一條線路。
- 相同商戶、相同幣別已有未關閉線路或待審申請時，阻擋重複申請。
- 核准時重新檢查幣別及商戶狀態；核准同一筆不能重複建立。
- 核准建立線路，不等同遊戲、正式串接與憑證已開通。線路初始待配置，避免演示成核准即已能投注。
- 駁回保留原因且不變更商戶主檔狀態；可補充後重新申請。
- 申請紀錄顯示幣別、申請時間、原因、審核狀態、審核說明、建立線路代碼。

## 限紅設定

- 總後台：商戶詳細 → 線路詳細 → 遊戲配置，選擇遊戲中心提供的適用方案。
- 商戶：遊戲中心 → 遊戲詳細 → 幣別與限紅 → 設定限紅。
- 選項只包含該遊戲、該幣別、啟用中的方案；顯示名稱、最低／最高投注及幣別。
- 無適用方案時不可保存，不用固定的標準／低額／高額名稱代替真實方案。
- 保存時再次檢查方案是否仍可用，拒絕跨商戶、跨線路、跨遊戲或跨幣別選擇。
- 商戶不能修改方案內的投注金額、RTP、Jackpot 或遊戲主檔。
- 保存選擇後，總後台與商戶查看相同方案。記錄操作人、時間、線路、遊戲及修改前後方案。
- 歷史注單與對帳保留當時使用的設定／快照；新設定不回寫歷史結果。

## UI 排列

- 商戶線路頁：頁首「申請幣別線路」；線路清單／申請紀錄兩個頁籤。
- 申請對話框：商戶唯讀 → 幣別 → 原因；底部取消／送出申請。
- 遊戲詳細：基本資料與 RTP 唯讀 → 幣別與限紅表格 → 限紅操作紀錄。
- 限紅表格：線路、遊戲、RTP、幣別、目前方案、投注上下限、設定限紅。
- 選擇對話框：線路唯讀 → 方案選擇；底部取消／保存。
- 手機表格可橫向捲動，操作區不可與內容重疊。

## 演示與正式系統界線

本次以本地前端狀態及保存機制演示申請、審核、限紅選擇。正式 PRD 仍要求服務端授權、原子核准與建立、並發／重複請求控制、跨使用者資料同步、不可竄改的稽核紀錄，以及限紅版本與交易快照。

不以模擬紀錄數字是否完全對齊判定原型完成；以角色能否完成正確流程、不可執行越權操作、畫面結果是否符合上述規則驗收。
