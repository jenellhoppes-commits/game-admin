# 第一階段驗收清單

狀態：待開發交付；本清單不是通過報告。

| 編號 | 操作 | 預期 |
|---|---|---|
| P1-01 | 分別選管理者、代理、商戶並使用相符帳號登入 | 同站點，正確首頁、選單、角色名稱 |
| P1-02 | 選代理入口但使用商戶帳號 | 拒絕登入，不殘留登入狀態 |
| P1-03 | 未登入先開代理合法深連結，再以代理登入 | 返回授權頁，沒有重導循環 |
| P1-04 | 商戶登入時 redirect 指向管理者或代理路由 | 不載入他角色資料，回自身首頁或拒絕 |
| P1-05 | 代理登入後直接輸入 /dashboard、/business/merchants | 拒絕存取總後台 |
| P1-06 | 管理者登出後登入代理，再登入商戶 | 舊頁籤、快取、列表與個人資料不殘留 |
| P1-07 | 各角色刷新首頁及合法詳細路由 | 身分及對應路由正常恢復 |
| P1-08 | 不同角色首頁 | 共用原有 layout，無 iframe 或外部端口跳轉 |
| P1-09 | 對帳中心與異動紀錄 | 無供應商；代理、商戶、差異、紀錄正常 |
| P1-10 | 舊供應商路由 | 不載入已移除供應商功能 |
| P1-11 | 桌機、手機，明暗主題 | 登入/選單/首頁可操作，內容不被遮擋 |
| P1-12 | 總後台遊戲、商務、下注與對帳 | 原功能回歸正常 |

逐項記錄版本、測試身分、實際結果及證據。前端 mock 結果與正式 API/後端驗權驗收分開。

本地現況盤點：登入 localUsers 是 super/admin/user；MenuProcessor 依 roles 過濾；user.logOut 有保留頁籤邏輯；partner-admin 原型是獨立 hash 路由，不能直接當共用總後台整合已完成。
