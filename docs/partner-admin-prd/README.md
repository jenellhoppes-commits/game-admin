## 版本與引用

Markdown 是維護來源。跨文件使用 MCH／AGT／XADM 前綴，例如 MCH/AC-01、AGT/Q-02、XADM/D01。規格、User Story、驗收條件與工作單應同步更新。

【基線】來自既有 V4.0 已確認規則；【延伸草案】為本次補足的產品行為。除明示基線外，兩份新後台的頁面、角色、預設值、外部申請及權限細節均為延伸草案。未決事項保留決策編號，不能用演示值或臨時程式預設取代決議。

`reference` 封存本次依據的 V4.0、GAP V4.1、LOB V1.0 及先前 SOP 落實對照，避免總後台驗收中的修改悄悄改變本包基準。後續收到新規格時先登記 CR，再判斷三端影響。封存檔中原有相對附件引用屬來源文字，完整原交接包另存於上一版目錄。

本次交付為產品規格與協作草案，沒有變更既有總後台、實作 API、執行正式交易或建立 Plane 任務。
