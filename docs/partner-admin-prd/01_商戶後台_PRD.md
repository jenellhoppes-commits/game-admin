## 1 這頁是什麼

商戶後台供商戶人員查看自己與遊戲商合作的營運資料、核對結果、維護授權範圍內的串接作業並追蹤申請。商戶後台帳號是操作人員；大廳玩家是線路會員；兩者不能共用權限或登入憑證。

### 1.1 已確認基線

| 規則 | 商戶端行為 |
|---|---|
| 商戶必綁代理、代理最多三級 | 顯示自己的直接所屬代理；不瀏覽其他商戶或代理樹 |
| 一線路一交易幣別 | 需要新交易幣別時申請新線路，由總後台建立／核發 |
| 一會員一線路一幣別一錢包 | 同名外部會員在不同線路分別列示；不能搬移、合併或切換錢包幣別 |
| 商戶層錢包模式 | 所有線路沿用同商戶模式，不在商戶端逐線路任意切换 |
| 商戶乘遊戲的 RTP | 看適用固定方案；不允許線路級 Override，不編輯理論 RTP 核心值 |
| 線路乘遊戲的開通及限紅 | 查看核定方案並提出配置申請；不能自由改底層方案 |
| 注單與交易分離 | 注單看局結果，交易看資金動作；一局可有多筆交易 |
| 歷史快照與 Replay | 看核准公開的盤面與重播，只還原歷史，不重新 RNG |
| 同幣別 Pool | 看自身線路參與情況；不能混幣或改 Pool 水位 |
| 原幣統計與 USDT 預設結算 | 不將 TWD 與 USDT 原幣相加；正式金額依鎖定匯率與條件快照 |
| 外部匯率呈現 | 僅見最終適用／正式結算匯率，不能取得內部調整或市場來源拆項 |
| 總後台為 Master | 商戶申請不等於變更生效；敏感變更由總後台審核並執行 |

### 1.2 角色草案

商戶管理員管理本商戶操作帳號與可授權角色；營運看遊戲、線路與營運報表；客服看授權線路的會員、注單、交易與 Replay；技術人員處理串接與測試；財務看商務條件、對帳與結算；稽核者唯讀看授權紀錄。預設角色可組合，但帳號管理權不自動包含技術秘密、財務或會員明細。

有效權限是商戶邊界、已授角色、線路範圍、欄位敏感級別及環境範圍的交集。無線路授權時顯示無可用範圍，不能自動回退成整個商戶。

## 2 這頁不做什麼

| 不做的事 | 責任歸屬 |
|---|---|
| 建立玩家、管理玩家密碼、存提與 KYC | 商戶自己的玩家平台 |
| 新增／改掛所屬代理、核定商業條件 | 總後台商務與審核中心；商戶只提出申請 |
| 修改 RTP Math、限紅底層模型、Jackpot Trigger | 總後台與遊戲服務 |
| 直接補款、退款、沖正或重送正式扣款 | 資金服務及總後台授權處理；本端只提異常案件 |
| 設定風控門檻、解除遊戲商限制 | 總後台風控；商戶可查對外原因並提出申覆 |
| 鎖定／作廢結算或標記已付款 | 總後台財務；款項支付另屬外部流程 |
| 查別人的 Pool 貢獻、得獎會員或線路 | 不提供；共享 Pool 不代表共享參與者明細 |
| 代理推廣、招商獎勵、佣金自由計算 | 代理產品或尚未核定商務規則 |

## 3 名詞說明

| 名詞 | 定義 |
|---|---|
| 商戶操作帳號 | 綁定單一商戶的工作人員身分；不等於玩家會員 |
| 申請單 | 商戶提出的目標變更與理由；連接總後台處理結果 |
| 業務狀態 | 線路、遊戲或交易本身的當前狀態 |
| 審核狀態／執行狀態 | 是否核准與是否完成變更，分開顯示 |
| 串接健康 | 最近探測或 Callback 結果與時間；不等於線路已正式開通 |
| Credential | 服務串接憑證；只供受授權商戶技術人員，不供代理或玩家 |
| Sandbox | 測試環境；憑證、會員、交易与正式環境隔離 |
| 理論 RTP／實際 RTP | 核定方案值／統計派彩除投注，不可互相覆寫 |
| 結算確認 | 商戶對指定版本資料表示同意；不等於財務鎖定或支付 |
| 原始結果的外部投影 | 經白名單篩選的歷史結果欄位；不是內部完整 JSON |

## 4 畫面內容

### 4.1 IA 與共用結構

沿用 V4.0 的 11 個一級入口。申請紀錄放在相關模組內；不另複製總後台審核中心。Detail Page 不進 Sidebar。

| 一級入口 | 子頁或主要內容 | 詳細頁／關聯 |
|---|---|---|
| 儀錶板 | 原幣營運摘要、異常與待辦 | 鑽取注單、交易、申請或結算 |
| 遊戲中心 | 可合作遊戲、已開通遊戲、配置申請 | 基本資料、RTP、線路限紅、展示能力 |
| 線路管理 | 自身線路、新增／變更申請 | 幣別、環境、開通狀態、大廳配置、歷程 |
| 串接中心 | 文件、環境設定、憑證、測試、跳轉追蹤 | Callback 結果、請求摘要、變更申請 |
| 會員中心 | 自身線路會員、對外限制狀態 | 基本資料、餘額、遊戲、注單、交易 |
| 交易中心 | 注單列表、交易列表、異常回報 | 七區注單詳細、交易關聯、處理回覆 |
| 獎池 | 參與 Pool、參與配置、自己的派發 | 級別、自己的流水／紀錄、申請 |
| 報表中心 | 商戶、線路、遊戲、會員、交易報表 | 匯出工作與相同條件鑽取 |
| 對帳／結算 | 對帳單、差異回報、結算單 | 幣別明細、條件與匯率快照、確認歷程 |
| 公告通知 | 遊戲維護、上新、申請與財務通知 | 內容、適用線路、閱讀狀態、關聯對象 |
| 帳號與權限 | 成員、角色、個人安全、操作紀錄 | 線路／環境範圍、有效權限、歷程 |

Header 顯示商戶名称、目前環境、線路範圍、時區、操作者。跨線路列表可選「全部已授權線路」，但金額仍分幣。切換環境清除不適用的選取與憑證內容，不沿用前一環境的操作表單。

### 4.2 各模組流程

**儀錶板：**顯示投注、派彩、商戶視角遊戲輸贏（投注減派彩）、投注會員數、局數、實際 RTP、交易異常與待確認對帳。遊戲輸贏不等於商戶營收或應付金額。各卡有期間、幣別、更新時間及資料口徑。GAP 未決退款、Jackpot 口徑沿用 Q-05；未定版指標顯示口徑待確認，不造正式金額。

**遊戲中心：**可合作目錄與線路已開通清單分頁或分籤顯示。遊戲詳細提供核定名稱、類型、裝置、語系、理論 RTP、限紅方案、維護／待上架狀態與試玩能力。申請開通指定遊戲與線路、變更核准方案引用或停用均建立申請單。是否允許商戶自行緊急停用見 Q-01；未核准前無直接開關。試玩僅進演示或 Sandbox，不能用工作人員身分偽装正式玩家。

**線路管理：**列出每條固定交易幣別線路及其環境設定。新增申請先選核准幣別、用途、環境、聯絡人與希望啟用時間；不能直接指定已生效 UID、Secret 或自行改錢包模式。同幣多線路仍待上游決策。申請通過但未執行時保留舊資料；正式啟用須總後台完成核發。大廳設定顯示正式／演示入口、展示版本、允許語系與返回目標；修改以申請方式處理，不提供玩家代登入。

**串接中心：**商戶技術人員按線路與環境看對應版本文件、端點與必要設定。IP／Callback／返回網域變更填理由並顯示差異，送總後台審核；測試成功只記錄測試能力，不自動開 Production。既有 Secret 預設不回顯；新憑證交付、一次顯示／下載與輪替過渡期見 Q-03。未完成安全方案前只能看狀態並申請核發。測試入口只操作核准 Sandbox 測試資料，阻擋自由輸入任意遠端目標。跳轉追蹤顯示發起、核發與失敗狀態，不包含可重用 Token；玩家大廳與伺服器對伺服器 API 分開授權。

**會員中心：**列出本商戶授權線路會員。展示外部識別、內部編號、線路、幣別、首次與最後遊戲、商戶來源狀態、遊戲商限制的對外摘要。單一錢包僅顯示商戶最後回傳餘額與時間；轉帳錢包取遊戲錢包服務；未知不能補零。商戶端 V0.1 不新增玩家、不搬線路、不改餘額。限制申請／申覆附會員、範圍、原因與期間，不能直接撤銷遊戲商限制。

**交易中心：**注單詳細保持七區：基本資料、遊戲結果、遊戲盤面、結果重播、關聯交易、異常紀錄、原始結果。後三區只輸出經授權的外部欄位；Seed、內部 Math、Debug、Secret 一律不下發。未授權頁籤顯示無查看權限，不能把內容藏在前端資料裡。Replay 使用當局版本，素材缺失時顯示事件摘要與缺失提示。交易逾時保留未知／处理中；「回報差異」不等於再次扣款或退款。商戶可追蹤回報與外部回覆，不能讀內部風控研判筆記。

**獎池：**顯示自己參與的同幣 Pool、級別、核准參與條件與自己的中獎紀錄。Pool 共用水位是否公開、更新延遲由 Q-04 決定；若允許，標明「共享獎池水位」，不可當成商戶資產。流水僅自己的貢獻／派發及必要公開事件，不傳其他參與者。申請參與需同幣、線路啟用、遊戲開通且支援 Jackpot；退出生效與進行中局數處理等待規則，不溯及改寫歷史。

**報表中心：**原幣、期間、時區、環境及測試範圍完整顯示。正式報表預設排除 Sandbox、演示與測試身分。若授權包含測試，另明示範圍。匯出以相同查詢建立工作，生成及下載時均重驗權限；已撤權檔案不得繼續下載。會員明細、財務、匯出是獨立權限，不因可看總數而可下載個資。

**對帳／結算：**商戶查看自己的條件版本、原幣彙總、最終適用匯率、結算幣別、對外調整與結算金額。對帳單可確認或回報差異；差異附原交易／局號、金額、幣別、說明與附件，不改原紀錄。總後台調整資料版本後，舊確認不沿用；需重確認。已鎖定結算只可查閱或提出更正申請。應付／應收方向必須由後端明確提供，不從正負數猜測；未有完整公式或鎖定匯率顯示未定案。代理成本、價差與內部匯率調整不對商戶顯示。確認責任與逾期規則見 Q-06。

**公告通知：**只顯示適用商戶／線路／角色的已發布公告與自身業務通知。站內閱讀狀態不代表同意商務變更。通知連結開啟時重驗對象權限；已撤回內容顯示不可用。Email 是否启用及內容範圍見 Q-08；敏感內容不放通知標題。

**帳號與權限：**邀請工作人員、停用、角色与線路授權均留歷程。授權集合不能超過自己的可授權上限；財務、技術秘密与匯出分權。變更權限後撤銷失效會話與下载資格。不得自行刪除最後一名有效管理員；交接先有另一位具資格的人員。本人變更 MFA／恢復及敏感授權流程見 Q-07，暫未定案項不提供跳過選項。

## 5 欄位說明

### 5.1 共用格式

| 欄位 | 内容與規則 | 無資料時顯示 |
|---|---|---|
| 識別與名稱 | 名稱加不可變編號；會員外部識別必須配線路 | 未提供；必要識別缺失阻擋寫入 |
| 金額 | 原幣代碼、幣別精度、數值、對象視角 | 未取得；確實為零才顯示 0 |
| 比率 | 理論／實際標籤，百分比格式 | 未設定或不適用；分母為零不算 0% |
| 時間 | 顯示年月日時分秒、時區及資料更新時間 | 未發生／未提供，不能用今天代填 |
| 狀態 | 各維度獨立代碼與中文 | 未知狀態；保留追蹤並禁止不安全寫入 |
| 申請原因 | 文字；敏感變更必填 | 請填原因，不接受空白送出 |
| 敏感內容 | 後端白名單與遮罩 | 無權限不傳值；不以可推算拆項替代 |

### 5.2 模組欄位

| 頁面 | 核心欄位及約束 | 缺值／例外 |
|---|---|---|
| 儀錶板 | 期間、線路、幣別、投注、派彩、輸贏、局數、會員數、實際 RTP、待辦 | 未算完顯示更新中；與列表計數同範圍 |
| 遊戲列表／詳細 | 代碼、名稱、類型、裝置、語系、主檔狀態、開通狀態、RTP 版本、限紅版本、展示版本 | 尚未開通與維護分開；未知 RTP 不顯示示例值 |
| 線路列表／詳細 | UID、幣別、錢包模式、環境、開通狀態、遊戲數、建立／生效日 | 審核中不捏造正式 UID 或啟用時間 |
| 申請表 | 類型、線路、目標值、舊版本、原因、聯絡方式、期望日期、附件 | 期望日期不是承諾生效日期；附件可選依類型 |
| 串接設定 | 線路、環境、文件版本、Credential 狀態與指紋、核准 IP／Callback、最後測試結果與時間 | 沒測過顯示未測試；Secret 不預填 |
| 會員 | 內外編號、線路、幣別、來源狀態、限制摘要、餘額來源／時間 | 不可取得時顯示未取得，限制細節依公開範圍 |
| 注單／交易 | 局／注單／交易號、遊戲、會員、線路、原幣、投注／派彩、交易類型、業務狀態、發生時間 | 未結算不顯示最終输贏；回滾顯示原交易關聯 |
| Replay | 當局版本、階段、事件、素材能力、可播放狀態 | 缺素材可看文本事件，不以現版重算 |
| Pool | Pool／Level、幣別、自己的線路與參與規則、公開水位、自己的派發與局號 | 不公開水位標示未提供，不能當零 |
| 報表／匯出 | 條件摘要、生成時間、資料截止、檔案狀態、到期時間 | 無結果顯示查無資料；生成失敗保留重試 |
| 對帳／結算 | 單號、版本、期間、原幣、計算基礎、自己的條件、對外匯率、結算幣、方向、金額、確認／鎖定時間 | 未定公式或匯率顯示未定案；不生成假正式金額 |
| 差異單 | 類型、關聯單據、幣別、爭議金額、說明、附件、處理摘要 | 原幣與結算幣不混填；無回覆為待處理 |
| 公告／通知 | 標題、類型、發布／生效時間、可見範圍、閱讀狀態、關聯對象 | 對象不可見就不展示內容 |
| 帳號／紀錄 | 操作者、角色、線路／環境、動作、對象、前後值、時間、結果 | 未登入顯示尚未登入；秘密前後值均遮罩 |

## 6 狀態說明

以下代碼為外部契約候選，正式定版前映射上游；不同維度不能壓成一個「啟用」。

| 維度 | 代碼 → 顯示文字 | 轉換與限制 |
|---|---|---|
| 線路開通 | pending → 待開通；active → 已開通；suspended → 暫停；closed → 已終止 | 由總後台執行結果決定；不能以測試通過取代 |
| 遊戲主檔 | enabled → 啟用；maintenance → 維護；disabled → 停用 | 與線路遊戲開關及發布版本獨立 |
| 線路遊戲 | not_enabled → 未開通；enabled → 已開通；disabled → 已停用 | 有開通仍須通過主檔、模式與會員資格 |
| Credential | not_issued → 未核發；active → 有效；rotating → 輪替中；revoked → 撤銷；expired → 過期 | 生效與過渡依安全方案，不傳秘密 |
| 申請 | draft → 草稿；submitted → 已送出；needs_info → 待補件；approved → 已通過；rejected → 已駁回；cancelled → 已取消 | 送出後凍結申請版本；待補件重送新版本 |
| 執行 | not_started → 未執行；processing → 執行中；succeeded → 已生效；failed → 執行失敗 | 審核通過不代表成功；失敗不回寫成功業務狀態 |
| 注單 | in_progress → 進行中；settled → 已結算；cancelled → 已取消；voided → 已作廢 | 顯示遊戲服務狀態與時間；不由前端計時推定 |
| 交易 | processing → 處理中；succeeded → 成功；failed → 失敗；unknown → 結果未明；reversed → 已沖正 | 未明不直接重送資金；沖正保留關聯 |
| 商戶對帳確認 | pending → 待確認；disputed → 有異議；confirmed → 已確認；superseded → 版本已更新 | 確認綁單據版本，新版本須重新確認 |
| 結算 | draft → 草稿；pending_lock → 待鎖定；locked → 已鎖定；voided → 已作廢 | 外部只見核准公開版本；不是付款狀態 |
| 匯出 | queued → 排隊；processing → 生成中；ready → 可下載；failed → 失敗；expired → 已過期 | 下載再次驗權，過期重建 |
| 操作帳號 | invited → 待啟用；active → 啟用；locked → 鎖定；disabled → 停用 | 邀請逾期與帳號停用分開；失效會話撤銷 |

申請撤回只允許後端確認尚可撤回的階段；與審核／執行競爭時以伺服器結果為準。緊急線路停用不依靠送申請成功假裝立即生效。

## 7 查詢排序與分頁

| 申請／差異 | 類型、申請人、對象、審核、執行、建立時間 | 建立時間倒序；20 筆 |
| Pool／派發 | 自己線路、Pool、Level、幣別、遊戲、期間 | 事件時間倒序；20 筆 |
| 報表／結算 | 期間、時區、線路、原幣、結算幣、狀態、單號 | 報表期間、單號倒序；20 筆 |

數值為延伸預設，最大查詢期間與保留年限由 Q-09 定案，不直接套用玩家大廳的最近三個月。資料時間採起始含、結束不含的統一區間；畫面日期轉換依顯示時區，跨日／夏令時間由後端處理。

改條件回第一頁。鑽取與返回保留條件，網址只保存非秘密條件；伺服器重新核對商戶與線路。分頁總數、選項與匯出同權限；新查詢完成後，舊回應不能覆蓋。空範圍不回傳全域統計。

### 8.1 申請與稽核

商戶建立草稿 → 驗證目標及權限 → 送出固定版本 → 總後台補件／駁回／通過 → 後端執行 → 商戶端顯示結果及新版本。全程使用同一業務關聯，可查看對外回覆與時間，不公開審核者私人聯絡資訊或內部意見。相同送出識別重試不得建立兩筆申請；若已有相同待審目標，提示關聯申請。

寫入、匯出、憑證交付與敏感查詢保留操作者、商戶、線路、環境、動作、對象版本、時間、結果及追蹤編號。稽核不可由商戶刪改，附件與下載連結不得永久公開。

## 9 頁面狀態

| 狀態 | 畫面與處理 |
|---|---|
| 載入中 | 分區載入；不顯示假的零餘額或零結算 |
| 查無資料 | 保留條件、顯示清除篩選；與尚未開通分別提示 |
| 全頁錯誤 | 顯示重試、追蹤編號；保留非秘密查詢 |
| 局部失敗 | 列表可用時保留；餘額／Replay／統計失敗各自提示 |
| 無權限／範圍撤回 | 清除舊敏感內容，阻擋深連結及下載，不展示他人總數 |
| 會話過期 | 要求重新驗證；不自動重送上一筆敏感表單 |
| 版本衝突 | 顯示已更新，重讀差異後重提；不覆蓋新版本 |
| 申請已通過但執行失敗 | 保留申請結果與失敗執行，舊業務配置仍有效 |
| 回報逾時 | 先查原申請結果，再以同一識別重試 |
| 素材缺失 | 顯示历史事件与缺失原因；不重算局結果 |
| 匯率／公式未定 | 金額為未定案，禁止確認假正式值 |
| 附件失敗 | 顯示檔案錯誤；未完成驗證的附件不能提交 |
