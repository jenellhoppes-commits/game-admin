## 三、缺陷複驗

### D1 — 未知角色錯誤回退 Admin（P0）— **Pass**

1. 空 roles、`R_USER`、未知角色、`R_ADMIN + R_UNKNOWN`、`R_AGENT + R_MERCHANT` 的 portal 與 home 解析均回傳 `null`。
2. 上述角色不可進入管理者、代理或商戶業務路由，只可進公共登入路徑。
3. `R_SUPER`、`R_ADMIN`、`R_AGENT`、`R_MERCHANT` 仍映射至正確後台與首頁。
4. demo User 與無效 Super fallback 已移除；無效持久化身分會清除並回 401。
5. UI 以 User 使用管理者入口時明確拒絕，URL 留在 Login，沒有 token、管理者選單或重導循環。
6. 拒絕後再以合法 Super 登入可正常到 `/dashboard`，證明錯配不污染下一次登入。

證據：`07-user-admin-entry-rejected`、`08-super-dashboard` 與 `partner-portal-stage1.test.ts`。
