## 範圍與基準

以 game-admin 現有工作樹與第一階段已通過的共用框架為基礎。先保存第一階段工作樹差異、未追蹤來源與回復副本，不重設既有修改。沿用 3006 背景服務，實際檢查連線與占用後處理，不建立獨立代理站點。原型參考 agent-admin/partner-admin-core；舊 03 V0.2 的独立網站規則已失效。

維持合法身分檢查、未知角色拒絕、帳號錯配拒絕、登出快取清理。使用既有 layout/Sidebar/router/Element Plus/明暗主題。不得使用 iframe 或另建完整殼層。

只開發第二階段，第三階段商戶完整功能等待使用者確認。不要 push 或部署，不恢復安排選手。

## 九個模組

1. 儀錶板：分別計算直屬下級、後代代理、直屬商戶、覆蓋商戶；依原幣顯示投注/派彩/遊戲輸贏/局數/活躍線路會員數，會員不下鑽個資。待辦連到對應列表。未定收益算法顯示計算規則待確認。
2. 代理關係：同一授權範圍的樹與列表；代理碼/名稱/層級/直接上級摘要/狀態/生效期間/直屬商戶數。提供新增下級、停用、移轉申請與歷程；L3 禁新增、父節點存在、無循環、子樹移轉不超 L3。送出只建申請，不直接更動有效關係。
3. 商戶管理：直屬/間接集合互斥，關鍵字/代理/狀態/幣別查詢，商戶碼/名稱/直接代理/關係生效日/幣別/線路數/原幣摘要。詳細只提供授權商務摘要，不提供會員/注單/交易/Credential/Secret/Callback/IP。只能申請新增自己的直屬商戶。
4. 商務條件：我的條件、授權直屬商戶條件、申請紀錄；版本/計算基礎/比例/生效起迄/週期/結算幣/狀態。可比基礎且期間一致才顯示百分點價差，不當收益；變更建立申請版本，不直接改已生效條件。
5. 代理報表：單一入口，代理/商戶/遊戲/幣別分析維度；期間/時區/樹範圍/直屬間接/幣別查詢，商戶數/線路數/局數/投注/派彩/遊戲輸贏。列表與分幣總計使用同集合，父子樹不重複計數。匯出必須有真正可下載的原型檔案或明確說明未支援，不能假成功。
6. 唯讀匯率報表：只顯示本代理業務及結算涉及幣別的正式適用匯率與歷史快照；基準幣/目標幣/最終匯率/生效起迄/版本/狀態。支援日期/幣別查詢、分頁、詳細、從對帳連到實際採用快照。不能新增/編輯/刪除/停用/鎖定/產生快照，不顯示內部來源/成本/加減點/備註。沿用第一階段 /agent/reports/exchange-rates；為對話規格 /agent/exchange-rates 提供同權限別名或重導。
7. 對帳／結算：僅本代理單據，對帳單/差異單/結算單；版本/期間/關係條件算法匯率快照/原幣基礎/結算幣/方向/金額/確認鎖定狀態。待確認且無未解差異才可確認；差異回報有關聯、金額、幣別、原因及追蹤結果。未定算法或缺必要匯率不生成正式金額；模擬可操作單据須明確標示既有核准示例而非新定算法。鎖定只讀，不表示付款。不可替下級或商戶確認。
8. 公告通知：只見本代理組織適用公告、自己的申請/對帳提醒，標記已讀，不推送下級每筆交易通知。
9. 帳號與權限：僅本組織員工，原型邀請/停用/角色/授權子樹/商務欄位/財務/匯出權限與操作紀錄；不能管理下級員工、商戶員工、總後台角色。撤權在 mock 範圍反映頁面/操作/下載資格，保留歷史紀錄。

## 資料與交互

總後台為 Master，優先從既有 store 整理代理可見資料投影，不建立互相衝突的第二套主資料。前端 mock 不宣稱正式後端資料隔離；代理 UI 不載入或展示不必要敏感明細。申請可於共用 mock 追蹤；完整三端聯動驗收仍在第四階段。

所有列表查詢/重置/Enter/分頁20、50、100/詳細返回狀態正常；更新條件回第一頁。0、缺資料、無權限、不適用不可混用；空態錯誤態清楚。已鎖定歷史關係及條件不可回改；收益算法、移轉後歷史查閱及連鎖停用未定不得自行擴展。
