## 1 這頁是什麼

代理後台供代理人員管理自己合作範圍內的商務資料、查看旗下營運彙總並對帳。它不是遊戲會員的代理登入入口，也不是商戶後台的超級帳號。

### 1.1 既有規則與預設邊界

| 規則 | 行為 |
|---|---|
| 固定最多三級 | 層級為平台全域 L1／L2／L3；L2 登入仍是 L2，畫面樹根不能重新算成 L1 |
| 自身代理樹 | 可見自己的節點與被授權後代；不可見兄弟樹或向上瀏覽父代理資料 |
| 商戶必綁代理 | 每個商戶有直接所屬代理；直屬與間接商戶分列，不重複算數 |
| 代理條件跟代理、商戶條件跟商戶 | 條件不依線路幣別拆分；展示生效版本 |
| 直接價差 | 同計算基礎及適用期間下，商戶條件減直接所屬代理條件；百分比相減的差為百分點 |
| 多層收益未定案 | 價差不是金額，不能累加各層價差或把整棵樹 GGR 當本代理收益 |
| 代理不是技術串接主體 | 不提供商戶 Secret、完整 Credential、Callback、IP 白名單及內部 API 技術資訊 |
| 原幣與結算分離 | 營運原幣不得混加；結算預設 USDT，以正式鎖定快照為準 |
| 匯率對外限制 | 只看最終適用／正式結算匯率，不能取得內部調整拆項 |
| 歷史不可改寫 | 關係、條件、對帳與結算保留版本；新關係不能改舊單归屬 |

### 1.2 授權草案

代理管理員管理本代理組織內工作人員；商務人員看授權商戶及可見條件並提出申請；營運人員看彙總報表；財務人員看本代理對帳與結算；稽核人員唯讀看可公開紀錄。代理管理員不能管理下級代理的工作帳號或替商戶配置角色。

代理樹可見性不自動授予所有欄位。建議初版：直屬商戶提供核准的合作資料與營運彙總；間接商戶提供核准的最小識別及彙總；商務條件、明細與聯絡資料需另授權。是否向上級公開下級條件與間接商戶條件見 Q-02，未核准前不下發。

代理端不提供會員個資、逐筆注單／交易或 Replay。若後續確有客服需求，另列決策與專門授權，不沿用「在代理樹內就全部可看」。

## 2 這頁不做什麼

| 不做的事 | 責任歸屬 |
|---|---|
| 直接建立正式下級、移轉商戶或改代理層級 | 總後台商務與審核；代理可提出申請草案 |
| 直接批准自己提出的條件 | 總後台審核；代理本地確認不代替正式核准 |
| 操作商戶線路、遊戲開關、RTP、限紅或 Pool | 總後台及商戶授權流程 |
| 取得 API 憑證、串接設定、技術測試入口 | 商戶技術人員與總後台 |
| 玩家 CRM、註冊、充值、提款、推廣佣金 | 商戶玩家平台或另立產品 |
| 改寫原始資金或手工建立收益 | 後端財務服務與總後台核准調整 |
| 自行修改匯率或內部成本 | 總後台財務，外部僅見核准結果 |
| 付款、鏈上交易或已付款證明 | 外部財務系統；本版結算不代表實際付款 |

## 3 名詞說明

| 名詞 | 定義 |
|---|---|
| 本代理 | 登入組織綁定的不可任意切換代理節點 |
| 直屬下級 | parent 等於本代理的下一層節點 |
| 間接下級 | 位於本代理後代樹，非直接子節點 |
| 直屬商戶 | 直接綁定本代理的商戶 |
| 間接商戶 | 綁定後代代理的商戶；不算本代理直屬商戶 |
| 覆蓋商戶數 | 授權樹中去重的商戶數；不可再加一次直屬商戶 |
| 條件 | 帶計算基礎、百分比或合約規則、生效期間的版本 |
| 價差 | 符合可比較条件的比例差，不等於应收金額 |
| 預估收益 | 僅在正式核准算法存在時依當期資料估算，標示未結算 |
| 正式收益 | 本代理已核准結算快照中的金額，含明確方向及调整 |
| 關係快照 | 某期間有效的商戶與代理歸屬，不由目前樹回算歷史 |

範例：代理條件 8%、其直屬商戶條件 10%，在相同基礎與期間下價差為 2 個百分點。這不是 2 元，也不能在多層收益公式未核定時推導出任何層級的正式收益。

## 4 畫面內容

### 4.1 IA 與共用結構

| 一級入口 | 子頁或內容 | 詳細頁與限制 |
|---|---|---|
| 儀錶板 | 直屬／覆蓋商戶、原幣營運、待辦 | 收益僅在有核准算法時展示 |
| 代理關係 | 目前代理樹、下級列表、關係申請 | 全域層級、關係生效歷史；不向上瀏覽 |
| 商戶管理 | 直屬／間接商戶、合作申請 | 合作摘要、原幣營運、可見條件、申請紀錄 |
| 商務條件 | 自己條件、核准可見商戶條件、變更申請 | 版本與有效期間、可解釋價差 |
| 報表中心 | 代理、商戶、遊戲、幣別營運彙總 | 不含逐筆會員／資金與技術設定 |
| 對帳／結算 | 本代理對帳、差異、結算單 | 核准公開的計算明細與快照 |
| 公告通知 | 維護、商務、申請、結算訊息 | 本人組織適用內容與閱讀狀態 |
| 帳號與權限 | 本組織工作人員、角色、安全、紀錄 | 不能修改商戶／下級代理工作帳號 |

Header 顯示本代理名稱與全域層級、資料期間、時區、操作者。代理樹篩選不等於切換登入組織。申請追蹤放在對應模組，不複製總後台風控或審核中心。

### 4.2 逐模組規格

**儀錶板：**直屬下級數、後代代理數、直屬商戶數、覆蓋商戶數分開顯示。營運卡包含各原幣投注、派彩、遊戲輸贏、局數與活躍線路會員數。樹彙總的會員去重使用線路會員識別，不用外部帳號。預估收益與正式結算分區；無已核准多層算法時顯示「計算規則待確認」，不默認零。代理未被授權的樹與欄位不出現在總數、排行或圖表。

**代理關係：**樹與列表共用相同權限及有效日期。L1 可見授權 L2／L3；L2 可見授權 L3；L3 沒有可新增下級。自己節點可以顯示合約必要的上級名稱摘要，但沒有可展開的上級節點或兄弟代理資料。新增下級、停用或移轉關係先提申請；審核與執行時重驗層級、循環與主資料版本。若整個子樹移轉，必須檢查最深後代是否超過 L3，不能只看被移動節點。

**歷史關係原則：**新報表按該期間關係快照歸屬；目前是否能看歷史則需獨立授權。建議移轉後舊代理只保留已授權且已封存的自身結算文件，不能持續查移出商戶的新營運；新代理也不自動取得移轉前明細。歷史查閱窗口與過渡權限見 Q-04，未完成決策時遇移轉資料應阻擋有爭議明細，不擅自歸給雙方。

**商戶管理：**用「直屬」與「間接」篩選區分合作關係。詳細呈現商戶代碼、名稱、直接所屬代理、關係生效日、狀態、核准交易幣別、線路數與原幣營運摘要。僅有「未開通／測試中／正式合作」的商務進度摘要；不傳 Credential、Callback、IP 或內部錯誤堆疊。招商新增申請記錄擬定商戶資料、直接代理、合作條件草案與聯絡資訊；是否允許替下級代理申請見 Q-01，預設只能為本代理直屬合作提出。

**商務條件：**自己條件唯讀看版本、計算基礎、比例、生效日、週期與結算幣。直屬商戶條件只按授權顯示；如可顯示雙方可比較條件，計算直接價差，單位為百分點。間接商戶的直接價差屬其直接代理的關係，不標成本代理收益。不同計算基礎或適用期間不得相減；負價差不改成零，提示商務確認。新條件申請建立未生效版本，與總後台確認後生效。未核定的提案不可被報表或正式結算引用。條件生效跨結算期是否按分段計算須見 Q-03，不能整期套用最新比例。

**報表中心：**提供按本代理、授權後代、直屬／間接商戶、遊戲、幣別、期間的營運彙總。從代理到商戶的鑽取只停在核准彙總層，不跳到會員或注單。直屬與間接集合互斥；彙總按商戶及線路去重，不能將父樹總額加上子樹總額。測試、演示、Sandbox 預設不納入正式報表。若提供參考換算，標示匯率時間、缺率及非正式結算，無匯率不補 1。下載依欄位與關係權限重新驗證。

**對帳／結算：**列表以「本代理」為結算對象，不顯示整棵樹所有人的結算單。單據包含期間、關係快照、算法／條件版本、原幣基礎、核定最終匯率、結算幣、對外調整、金額方向及對帳版本。核准計算分配可在本代理結算明細內解释，但不暴露其他代理的完整合約。無正式算法、歸屬規則或必要匯率時，不生成應付／應收正式收益。代理可確認或提差異；總後台鎖定／作廢／更正，代理不能改帳。確認的是本代理單據，不代表下級或商戶已同意，不替代其獨立對帳。

**公告通知：**限本組織適用的公開資訊与自己申請、對帳提醒。組織看得到子樹不代表應收到每筆下級財務通知。點擊連結重驗對象，不因通知保存了舊標題就延續已撤銷的存取。標記已讀不等於接受新條件。

**帳號與權限：**本代理管理員可管理自己員工，配置授權後代範圍、商務欄位、財務與匯出權限。角色只能在可授權上限內組合；新授權需同時符合最新代理關係。停用員工後撤銷會話及下載資格，保存舊操作紀錄。不得刪除最後有效管理員；不得藉新增角色取得總後台或商戶權限。登入、MFA、邀請過期與恢復規則見 Q-06。

## 5 欄位說明

### 5.1 共用欄位

| 欄位 | 內容與約束 | 無資料時顯示 |
|---|---|---|
| 代理名稱／編號 | 名稱配穩定識別；層級由總後台取得 | 未提供，不能由顯示樹深推算層級 |
| 關係與期間 | 直屬／間接、直接所屬、開始／結束、快照版本 | 無下級；歷史未知顯示待確認 |

| 預估收益 | 本代理、算法版本、基礎期間、適用條件、估值、生成時間 | 算法未定顯示計算規則待確認 |
| 結算單 | 單號、版本、本代理、期間、關係／條件／算法／匯率快照、方向、結算金額、確認／鎖定狀態 | 結算對象不是本代理則拒絕；不當已付款 |
| 差異單 | 原單與版本、類型、幣別、爭議金額、說明、附件、對外回覆 | 無回覆為待處理，內部成本不公開 |
| 通知 | 類型、標題、適用角色、發布／生效時間、已讀、關聯 | 已撤回或撤權不可讀內容 |
| 帳號／稽核 | 員工、角色、授權樹、欄位權限、動作、對象、時間、結果 | 不列下級代理員工；無歷程顯示查無資料 |

## 6 狀態說明

| 維度 | 候選代碼 → 顯示文字 | 規則 |
|---|---|---|
| 代理合作 | pending → 待合作；active → 合作中；suspended → 暫停；terminated → 終止 | 總後台決定；子樹處置需另有明確策略 |
| 代理關係版本 | scheduled → 待生效；effective → 生效中；ended → 已結束 | 按生效時間與版本，不能覆蓋舊關係 |
| 商戶合作 | pending → 待開通；testing → 測試中；active → 正式合作；suspended → 暫停；terminated → 終止 | 僅商務摘要，技術健康不在此狀態內 |
| 條件版本 | proposed → 提案；approved → 已核准；scheduled → 待生效；effective → 生效中；expired → 已到期 | 核准與時間生效不同；取消由上游狀態映射 |
| 申請 | draft → 草稿；submitted → 已送出；needs_info → 待補件；approved → 通過；rejected → 駁回；cancelled → 取消 | 送出凍結版本；不能自審生效 |
| 執行 | not_started → 未執行；processing → 執行中；succeeded → 已生效；failed → 執行失敗 | 執行前重驗關係、層級、版本 |
| 對帳確認 | pending → 待確認；disputed → 有異議；confirmed → 已確認；superseded → 已換版 | 每個版本獨立；不能代表別的代理確認 |
| 結算 | draft → 草稿；pending_lock → 待鎖定；locked → 已鎖定；voided → 已作廢 | 鎖定不表示付款；外部僅看核准公開版本 |
| 匯出 | queued → 排隊；processing → 生成中；ready → 可下載；failed → 失敗；expired → 過期 | 生成與下載重驗關係、角色及欄位 |
| 員工帳號 | invited → 待啟用；active → 啟用；locked → 鎖定；disabled → 停用 | 停用撤銷會話；本代理範圍內管理 |

樹關係異動、角色範圍異動或商戶移轉後，現有頁面及快取必須重新驗權。暫停代理是否連帶暫停商戶、線路及其他下級仍待 Q-01；不得由本端自行推導或執行連鎖停用。

## 7 查詢排序與分頁

| 頁面 | 查詢條件 | 排序與分頁草案 |
|---|---|---|
| 代理關係 | 名稱／編號、全域層級、合作狀態、關係有效日期 | 全域層級、名稱、穩定編號；樹分批展開 |
| 商戶 | 名稱／代碼、直屬／間接、授權下級、合作狀態、幣別 | 更新時間倒序＋編號；每頁 20 筆 |
| 條件／申請 | 對象、基礎、版本狀態、生效期間、申請人、執行狀態 | 生效時間或建立時間倒序；20 筆 |
| 報表 | 期間、時區、樹範圍、直屬／間接、遊戲、幣別 | 指標排序明示升降序；相同值按穩定 ID；20／50 筆 |
| 對帳／結算 | 本代理單號、期間、結算幣、確認／鎖定狀態 | 期間倒序＋單號；20 筆 |
| 通知／稽核 | 類型、已讀、操作者、對象、時間 | 發生時間倒序＋編號；20 筆 |

根節點、搜尋選項與計數都限制在可見樹，不先取全站再前端過濾。變更篩選回第一頁；代理樹搜尋命中子節點只呈現授權路徑，不洩漏根外父節點。空集合不能回退全部代理。

期間採起始含、結束不含，畫面顯示時區。歷史營運以期間歸屬快照彙總，當前授權另外驗證。跨關係／條件生效邊界須使用核准分段規則，未定案時不可輸出正式收益。保留年限与查詢上限見 Q-07。

### 8.1 跨端申請

代理提出資料與期望值 → 後端確認申請資格與目標 → 總後台審核 → 執行前重驗層級、關係與條件版本 → 生效後回傳對外結果。新增下級、建立商戶及移轉都是申請，不能因按了送出就在正式樹中出現新節點。

重送使用相同業務識別；已通過但未執行與已生效分開。不能自審；不能撤回已完成的執行。可補件或取消的階段由後端可用操作決定。修改、查敏感條件、確認、匯出與下載均保留本代理、操作者、對象、範圍、時間與結果。

## 9 頁面狀態

| 狀態 | 畫面與處理 |
|---|---|
| 載入 | 樹、摘要與列表分區呈現，不先顯示零收益 |
| 沒有下級／商戶 | 說明尚無合作對象；L3 不顯示可新增下級操作 |
| 查無結果 | 保留篩選，提供清除；不同於無權限 |
| 全頁／局部失敗 | 保留成功區塊与條件，失敗區顯示重試及追蹤編號 |
| 無權限 | 不傳根外／敏感資料，深連結拒絕，不洩漏對象是否存在 |
| 關係已移轉 | 重讀授權；清除不再可見的現況，歷史依核准保存政策 |
| 條件／算法缺失 | 顯示未定案，停止正式收益與確認；不補零 |
| 不可比較的條件 | 價差為不適用，顯示基礎或期間不一致 |
| 版本衝突 | 顯示新版本與重新檢視要求，不用舊快照覆蓋 |
| 已核准但執行失敗 | 新關係／條件未生效，保留目前正式資料 |
| 會話失效／撤權 | 清除敏感資料，重新驗證；不自動重送確認 |
| 匯出撤權／到期 | 不提供檔案；有資格時重新生成 |
