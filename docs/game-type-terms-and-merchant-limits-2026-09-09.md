# 遊戲類型商務條件與總後台商戶限紅｜2026-09-09

本文件為本次確認規格，與先前「全遊戲共用單一比例」說明衝突時，以本文件為準。

## 商務條件
- 每個代理、商戶的每個条件版本保存各遊戲類型 GGR 比例；例 SLOT 電子遊戲 5%、LIVE 真人遊戲 8%。95%／92% 為已更正的誤植，不採用。
- 類型沿用總後台遊戲分類資料；同類型只能有一個比例，0–100%，最多兩位小數。
- 新增版本至少需填一個類型；留空為未設定，不代表 0%，不自動套用其他類型。
- 版本共用結算幣別、週期、生效日、原因；更動建立新版本，不覆寫舊條件或歷史結算。
- 原型既有全域條件仍保留，顯示「歷史全域條件」，不自行分配給所有類型。
- 總後台：代理／商戶新增、條件版本編輯、詳細及列表摘要同步。
- 代理後台：新增直屬代理／商戶及修改直屬條件共用類型表單；我的條件唯讀。條件歷史與操作紀錄顯示各類型比例。
- 商戶後台：對帳／結算區顯示「我的商務條件（唯讀）」版本表，包括各類型比例、生效日、截止日、結算幣別、週期與狀態。
- 總後台版本先為草稿，確認未來生效版本時排程，日期到達才替換目前條件；代理直接保存版本沿用既有日期生效流程。
- 歷史結算快照保留原本數字；本次不新增或定案正式收益公式，也不以新條件回算歷史。

## 總後台商戶限紅
- 商戶詳細新增「限紅設定」，放在遊戲配置後。
- 以商戶×幣別線路×遊戲管理；與商戶端及既有線路詳細共用同一筆配置。
- 篩選：幣別、遊戲名稱／代碼。列表：幣別、線路、遊戲、限紅方案、最低／最高投注、更新時間、調整限紅。
- 只能選取遊戲及幣別相符、啟用中的總後台方案，不直接輸入上下限。
- 已取消授權遊戲不提供調整；保存時重新驗證方案及授權。
- 修改原因必填；前後設定、操作人、時間記入現有商戶及線路稽核紀錄。

## UI
- 遊戲類型名稱靠左、百分比輸入與 % 靠右；手機保留一列一類型。
- 長表單內容獨立捲動，標題及底部取消／保存固定，避免按鈕超出視窗。
- 商戶唯讀條件使用可橫向捲動表格，無編輯按鈕。
