# 代理統收與平台代收規格

本次先開放代理統收，平台代收僅列未啟用需求。適用新增商戶及三後台結算展示。

## 建立與設定

新增商戶必填收付模式，本階段固定為代理統收。新商戶依商務條件生效日啟用合作；不開放任意切換收付模式。未來切換須設定下一完整結算期間生效日，已出帳單據不能改用新模式。

## 收付責任

商戶向直屬代理付款；代理向上級代理付款；總代向平台付款。每張單保存付款方、收款方、收付模式及是否屬平台應收。商戶明細與代理彙總不能相加作為平台應收。平台只能確認收款方為平台的單據；代理只能確認收款方為本代理的直屬應收單。

## 代理後台

對帳頁新增直屬應收區塊，包含直屬商戶及直屬下級的單據。具有財務權限者可核帳／交付。自己的上繳單據保留唯讀交付結果，不自行代上級確認收款。

## 交付

保留手動差異調整、非零調整必填原因、整數實收、不四捨五入、餘額保留與交付後鎖定。負 GGR 依合約累積／清零。收款方不同的帳務不可互相沖抵。

## 平台代收（未啟用）

平台向商戶收款，另外產生代理傭金付款義務。傭金釋放是否依實收比例、多層分配、部分付款順序、退款追扣、模式轉換期間舊餘額歸屬均待確認。不以原型示範數字作為正式算法。

## 驗收

平台不得收商戶單；非收款代理不得確認；合法收款方可交付；鎖定後不可重複交付。三端顯示相同模式與收付對象。平台代收不可選。

原型沿用既有示範結算金額，此次修改收付責任與操作範圍；正式分遊戲類型、按成本及下開條件計價仍需按 PRD 計算規則驗收。雲端 PRD 尚未同步。
