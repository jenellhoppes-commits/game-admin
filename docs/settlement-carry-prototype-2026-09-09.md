# 多期交收結轉原型（2026-09-09）

已確認：累積模式的負 GGR 承接下期扣抵；正數計價後可交收或保留。清零模式也提供保留按鈕，不能清掉既有待交收金額。

原型入口：總後台對帳明細、代理對帳／結算、商戶對帳／結算的「交收結轉演示」。使用獨立 SLOT、USD、5% 示範，不改寫歷史單據。可重設並操作連續期別。

- 本期 GGR 只顯示本期；上期餘額分欄承接，不把歷史本期值重複加總。
- 扣抵後 GGR = 上期累積 GGR + 本期 GGR。
- 本期新增交收金額 = 正的扣抵後 GGR × 比例；負值或零不新增。
- 合計待交收金額 = 上期待交收金額 + 本期新增交收金額。
- 確認對帳後才能交收或保留；每次完成後進下一期，需再次確認才能操作。
- 保留：實際交收為零，全部待交收金額承接下期。
- 交收：本演示一次交收全部待交收金額，已交收部分不再結轉；不提供部分交收。
- 累積模式承接負 GGR，清零模式下期 GGR 從零開始；兩種模式都承接待交收金額。
- 每期留存上期／本期 GGR、扣抵後 GGR、上期待交收、本期新增、合計、實際交收及結轉欄位。
- 正式實作按對象、幣別、遊戲類型及適用條件版本分帳。跨期條件變更與精度、正式入帳串接仍須另訂；本演示固定類型、幣別及比例。

測試涵蓋負數連續扣抵、轉正、連續保留、待交收不重乘比例、完成交收、清零保留待交收。
